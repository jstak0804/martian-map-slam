# Three-minute demonstration

Open `18-eva-walkback-demo.html#mars`. All display assets are embedded.

1. **0:00–0:30 — Global context.** Pan/zoom the Mars overview, select a coordinate, and inspect region status. Explain that a background image does not imply global EVA analysis coverage. Enter Jezero.
2. **0:30–1:10 — Observations.** Open Observations. Show the two official PDS mesh products in their common local frame and their source links. Explain the empty registered coverage mask. Select a Navcam station to distinguish the rover location from its planned approach point. Open a nearby rover photo and its sol/distance caption.
3. **1:10–1:50 — Same mission, changed terrain.** Use `#jezero-evidence-demo`, compare Travel / Return / Time at site, choose a stay split, and apply Block test. Show the new route and times. The block is synthetic; it was not automatically inferred from the local mesh.
4. **1:50–2:35 — Shared clock.** Start the trip, open Visor, rotate the map and press N. Show the remaining trip estimate and photo provenance. Press Return now, then Start to follow the return route.
5. **2:35–3:00 — Limits and reset.** Show the 20% return-oxygen policy and coverage warning. Restart restores the original schedule; Clear block restores terrain. State that this is a model demonstration with approximate rover-photo selection, not a validated human EVA navigation system.
