## 1. recalc 스크립트 재현성
- **문제 [확인]:** `k_scenarios.py`, `model_b.py`, `sensitivity_hr_water.py`는 원본 `code/` 모듈을 불러온다. 계획 C 이후 그 기본값이 IST 모델 + 16방향이라, 다시 돌리면 "Pandolf 기준선"이 바뀌고 검증이 실패한다(9.721 ≠ 18.64).
- **수정:** 세 스크립트 맨 위(원본 모듈 import 전)에서 환경 변수를 고정한다.
  ```python
  os.environ["GALE_METABOLIC_MODEL"] = "pandolf_legacy"   # 이 스크립트는 '원본 모델' 기준으로 쓰였다
  os.environ["GALE_GRID_NEIGHBORS"] = "8"
  ```
  - `sensitivity_hr_water.py`는 `model_b`를 import하지만, 순서와 무관하게 스스로도 고정한다.
  - `plan_c_checks.py`, `js_parity.py`는 현재 모델을 검증하는 스크립트라 고정하지 않는다.
- **검증:** 세 스크립트를 다시 돌려 이전 결과와 같은지 확인한다.
  - k_scenarios: 18.643 / 13.292 / 10.028 km²
  - model_b: 검증 8개 통과, 90 kg ㄱ 7.32 km²(444 W 예비분)
  - sensitivity: 기준 6.42 km²

## 2. 대사량 하한 = 서 있는 대사량
- **문제 [확인]:** IST 평지 곡선을 측정 범위(0.62 m/s) 아래로 외삽하면 0.2 m/s에서 154 W로, 서 있는 대사량 222 W보다 낮다. 실제 지도 간선의 0.01%(641개, −36%보다 가파른 내리막)에서 일어난다.
- **근거 [확인]:** Looney 2019 식 1은 "서 있는 비용 상수(1.44 W/kg) + 0 이상의 보행 항" 구조다. 걷기 비용은 서 있는 비용보다 작아질 수 없다.
- **수정:** `metabolic_model.metabolic_rate_w`(ist_b)의 결과에 `max(대사량, 서 있는 대사량)`을 적용한다. 서 있는 대사량은 결정 D3대로 Pandolf 222 W이고, 근거가 약하다는 한계를 기록한다. 데모 JS `edgeO2`에도 같은 하한을 넣는다.
- **검증:** 하한 적용 간선 수, 면적 변화(무시할 수준 예상), Python–JS 일치를 다시 확인한다.

## 3. 심박 시연(보고서 16 코드)의 적용 범위 표시
- **문제 [확인]:** 새 모델 대사량(평지 444 W = 1516 BTU/h)은 Hoffmann 2021 자료의 최상위 구간(">1200 BTU/hr")을 넘는다. 그 결과 206 bpm 같은 값이 그대로 출력·그림에 나간다.
- **수정 (새 심박 모델을 만들지는 않음 — 화성 우주복 심박-산소 실측이 없음):**
  1. 회귀 적용 상한 `FIT_MAX_MR_W`를 코드의 가정값 1400에서 **원문 구간 경계 1200 BTU/h**로 바꾼다(원문 근거가 있는 값).
  2. 경로의 대부분(50% 넘게)이 상한 밖이면 다음을 한다.
     - 콘솔에 경고를 출력한다.
     - `heart_rate_o2_stats.json`에 `"hr_conversion_valid": false`와 이유를 기록한다.
     - 그림 제목에 "HR conversion not valid for this metabolic model (beyond Hoffmann 2021 data)"를 넣는다.
  3. k 추정 시연(합성 심박)은 "방법 시연"이라는 기존 표기를 유지하되, 같은 경고를 붙인다.
- **검증:** 실행 로그·JSON·그림에 경고가 나오는지, legacy 모델로 돌리면 기존 출력과 같은지(301 W = 1028 BTU/h는 1200 안이라 경고 없음) 확인한다.

## 4. 데모의 통신 두절 시간 표시
- **문제 [확인]:** `mins(m) = m / 평지 속도 / 60`으로 거리를 시간으로 바꿔 두 곳에 표시한다. 경사별 속도와 맞지 않는다(sol 1282 경로에서 약 3.4% 과소).
- **수정:** `pathStats`에서 칸 이동마다 `walkSpeed(경사)`로 시간을 누적하고(`darkT`, `maxRunT`), 표시를 그 시간으로 바꾼다. `mins()`는 쓰는 곳이 없어지면 지운다.
- **검증:** node로 sol 1282 경로에 대해 `pathStats` 시간 합계가 Python 트리 시간과 같은지 확인한다.
