상태: **완료 (2026-11-12).** K2·K3·K5 실험·반영, K4 적용(경보 k × 1.2, 예시 sol 678). CHANGELOG 18절.
배경: 사용자 결정 "역할을 나눠서 실험한 후에 적용"(CHANGELOG 17.15).

## K2. 지형·내리막 (역할 2)

### 근거 자료 [확인]
- **Kim 2023**(1 g, 우주복 없음, 10명), 정상 상태:
  - 평지 1,311 BTU/h(5.18 km/h)
  - 바위밭 1,439 BTU/h(4.96 km/h): 시간당 +10%(p = 0.13), 거리당 +15%
  - 혼합 지형(분화구·모래 언덕·15° 언덕) 2,071 BTU/h(4.84 km/h): 시간당 +58%, 거리당 +69%
- **Richmond 2015**: η는 Pandolf 움직임 항에 곱한다. 우리 조건(지구)에서 움직임 항은 전체의 26%이고, 우리 구현은 η 1당 전체의 18%다(CHANGELOG 17절 대화 기록).
- **Minetti 2002**: 맨몸, 경사 −45~+45%의 거리당 보행 비용 곡선(`references/minetti_eq.png`, 식은 원문에서 다시 확인 후 사용).

### 실험
- **K2a 바위밭 대조**
  - 우리 모델에서 η 값별 평지 대사량 증가(시간당·거리당)를 Kim 바위밭(+10% / +15%)과 나란히 놓는다.
  - 우리 대리 지표가 "바위밭"에 해당하는 칸에 주는 η 분포(상위 5·10% 칸)를 확인한다.
  - 판정: 현재 최대 η 1.5(+8.9%)가 바위밭 실측 범위 안인지.
- **K2b η 기준 맞춤**
  - η 효과를 Richmond 기준(움직임 항 26%)으로 다시 맞춘 경우를 계산한다(배수 26/18 ≈ 1.44를 지형 항에 곱함).
  - 기준 면적, η 바닥값 1.2 사례, 모래 시나리오(Hidden Valley 귀환 산소)를 계산한다.
- **K2c 내리막 경계 사례**
  - Minetti 곡선의 "내리막 ÷ 평지" 비율을 그대로 쓴 경우를 현재(LCDA × 우주복 축소), 축소 없음, 평지와 같음(J8)과 함께 놓는다.
  - 산출: 150 g 면적, sol 1282 귀환 산소.
- **K2d 혼합 지형** (계산 없음, 해석만)
  - +58%에는 언덕 경사(우리 모델이 따로 계산), 모래(우리 모래 시나리오), 분화구가 섞여 있다.
  - 그래서 하나의 배수로 바로 옮기지 않는다. 지형 항의 상한 근거로만 기록한다.

### 적용 후보 (K4에서 결정)
- η 범위 유지 또는 상향
- η 기준 맞춤(배수 1.44) 채택 여부
- 내리막 가정 교체 여부

## K3. 실시간 k 추정 (역할 3)

### 문제
- 경보의 예비분 침범은 k 추정이 대사 변화를 늦게 따라가서 생긴다(J9).
- 그런데 지금 시뮬레이션의 "실제 소모"는 순간적이다(대사가 바로 바뀜). 실제 몸은 지연이 있다. Kim 2023: 혼합 지형 정상 상태까지 6.72 ± 0.92분.
- 지연이 없는 합성 자료로는 지연 보정 방법을 공정하게 비교할 수 없다.

### 실험 설계
- **합성 자료에 생리 지연 추가:** 데모 템플릿에 분석용 `state.simLagTau`(분, 기본 0 = 지연 없음, 현재 동작)를 추가한다.
  - 실제 대사량 = 1차 지연(시간 상수 τ) ∘ (k_true × 모델 대사량).
  - 이 지연은 실제 산소 소모와 심박 모두에 적용된다(몸의 소모 자체가 늦게 따라감).
  - τ: 정상 상태(약 95% 도달) ≈ 3τ로 보고 6.72분 / 3 ≈ **2.2분**을 주 값으로 한다 [추론]. 민감도 1분, 3.5분.
- **추정기** (`state.simKEst`, 기본 "ratio10" = 현재):
  - `ratio10`(현재): 최근 10분 측정 대사 ÷ 같은 구간 모델 대사
  - `aligned10`(Kim DF 개념): 모델 대사에 같은 1차 지연을 적용한 뒤 나눔(측정과 예측의 시간 맞춤)
  - `aligned5`: 위와 같고 창 5분(잡음과 반응 속도의 교환)
- **k 여유:** 1.0 / 1.2(J9, Apollo +20% 선례)
- **스윕** (J9와 같은 25곳 × 시나리오 4 × 심박/압력 × 누설 0/10):
  - τ = 2.2: 추정기 3 × 여유 2 + 경보 끔 = 7규칙 → 2,800회
  - τ = 1, 3.5: 상위 두 규칙 + 끔 → 2 × 3 × 400 = 2,400회
- **지표:** 예비분 침범률·최대량, 산소 소진, 과잉 경보, 돌아선 지점 비율(J9와 같음)
- **검증:**
  - τ = 0, `ratio10`, 여유 1.0에서 J9의 N1 결과를 재현해야 한다.
  - I2 예시 회귀 테스트가 통과해야 한다(기본값 불변).

### 적용 후보 (K4에서 결정)
- 경보 기본 규칙(현재 / 여유 1.2 / 시간 맞춤 추정기 / 둘 다)

## 가정과 한계
- Kim 2023·2025는 지구 1 g, 우주복 없음이다. 지형 효과는 "비율"로만 옮긴다(우주복·중력에서 같은 비율이라는 보장은 없음).
- τ는 정상 상태 시간에서 추정한 값이다. 실제 우주복 보행의 대사 지연은 확인하지 못했다.
- 시나리오(급증·지침 등)는 여전히 합성값이다.
