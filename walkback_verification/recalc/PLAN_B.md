# 계획 B: 대사 모델을 실측 기반으로 바꿔 귀환 반경 다시 계산

상태: **구현 완료 (2026-11-09). 결과: RESULTS_B.md.** (다)는 다섯 곡선 회귀로 구현되어 (나)의 배수 방식을 대체함 · 근거: RESEARCH.md 1.1, 1.2절 · 안 A 결과: RESULTS.md

## 1. 목표와 안 A와의 차이
- 안 A는 Pandolf 비용 전체에 k를 곱했다. 그래서 평지와 오르막의 비율이 원래 모델 그대로였고, 최적 경로도 바뀌지 않았다.
- 안 B는 칸 이동 비용을 **실측 곡선**으로 바꾼다. 평지 비용과 오르막 추가 비용을 따로 둔다. 그래서 경로 선택, 왕복 비대칭, 경계 모양이 바뀔 수 있다.

## 2. 새 대사 모델 (속도 0.92 m/s 고정, 기존과 같음)

```
M_B(G, η) [W] = s × [ L + ΔG(G) ] × m_body × 20.1 kJ/L ÷ 60   +   T(η)
```
| 항 | 값 | 근거 |
|---|---|---|
| L: 평지 우주복 보행 (mL/kg/min) | IST-1 그림 22, 0.32 g 추세선의 0.92 m/s 값(눈 판독 약 17) | 화성과 같은 총 무게, MKIII 121 kg |
| ΔG(G): 오르막 추가 (mL/kg/min) | IST-2 그림 36, 0.32 g 추세선(0/10/20/30%)을 2차식으로 맞춤. 판독 속도 0.77 m/s를 0.92 m/s로 옮길 때 속도비 1.19를 곱함 | 같은 조건의 경사 시험 |
| 내리막 (G < 0) | ΔG = 0 (평지와 같음) | 기존 모델과 같은 보수적 가정. 실측 없음 |
| T(η): 지형 거칠기 | 기존 Pandolf와 같은 절대 증가량 (η − 1)(W + L)(1.5V²) | 지형 처리를 기존과 같게 둬서 비교를 쉽게 함 |
| m_body | 75 kg (기존 가정) | mL/kg 정규화 값이 체중에 그대로 옮겨진다고 가정 |
| s: 변형 배수 | 중심 B = 1.00, 높은 B = EWT ÷ IST-1 (1.25 m/s에서 판독, 약 1.15) | 높은 B는 EWT(3/8 g 실제 무게, 덜 익숙한 상태)를 대표 |
| 경사 상한 | 20° (기존과 같음) | IST-2는 30%(약 17°)까지 시험했으므로 17~20°는 외삽 |

- **예상 크기(눈 판독 기준):** 평지 약 427 W(산소 109 g/h, 기존의 1.42배). 오르막 추가분은 10% 경사에서 +66 W(기존 +201 W), 20%에서 +222 W(기존 +402 W).
- **예비분:** 새 모델의 평지 30분치(약 55 g). 보고서 15와 같은 정의이며, 안 A의 "예비분 k배"와 같은 성격이다. 안 A의 고정 38.6 g도 민감도로 함께 낸다.
- **냉각수와 누설:** 냉각수는 새 대사량에 비례한다(suit_cooling 식 그대로). 누설은 안 A와 같이 0과 14.9 g/h 두 경우를 계산한다.

## 3. 그림 판독 방법 (구현 1단계)
1. PDF에서 그림 쪽을 300 dpi로 렌더링한다.
2. 축 눈금 두 개의 화소 좌표로 축을 보정한다. 보정 좌표는 파일에 기록한다.
3. 0.32 g 추세선 색(하늘색)의 화소를 x마다 모아 y 중앙값을 취한다. 같은 색 산점도 기호는 선 두께보다 큰 덩어리를 제외해서 걸러낸다.
4. 판독 점 CSV와 원본 위에 겹친 확인 그림을 저장한다. 육안 판독값(17 / 16.2·18.4·23.6·31.5)과 ±1 mL/kg/min 안에서 맞는지 확인한다.

## 6. 검증
1. 비용 함수를 Pandolf로 바꿔 넣으면 기존 결과(18.643 km², 경로 7.26 km)가 그대로 나온다. 그래프 생성 코드 자체를 확인하는 단계다.
2. 판독값이 육안 판독과 ±1 mL/kg/min 안에서 맞는다.
3. ΔG는 경사가 커지면 줄어들지 않는다. ΔG(0) = 0이다.
4. 경사가 없는 평지 격자를 만들어 계산한 면적이 원(반경 = (예산 ÷ 평지 산소율) × 속도)과 맞는다.
5. 중심 B의 평지 비용이 IST-1 0.32 g 데이터 산점 범위(0.9 m/s 부근 약 13~19) 안에 있다.

## 7. 가정과 트레이드오프
- MKIII 121 kg, 2007년 시험이다. 질량(관성)은 프로젝트 가정 90 kg보다 크고, 무게는 거의 같다. 관성 비용 때문에 중심 B가 90 kg 우주복보다 비쌀 수 있다.
- 추세선은 6명 데이터의 2차 맞춤이다. 0.9 m/s 부근 산점은 13~19 mL/kg/min으로 넓다.
- 경사 데이터는 0.77 m/s에서 측정했다. 0.92 m/s로 옮길 때 속도비를 곱하는 것은 가정이다(경사 일 ∝ 속도).
- 내리막은 실측이 없어 기존처럼 평지 비용으로 둔다.
- 맨몸 자료(Kluis 2025, Brown 2018)는 모델에 넣지 않는다. 우주복을 입은 채 같은 무게에서 직접 잰 값이 있기 때문이다. 교차 확인에만 쓴다.
- 속도 고정 0.92 m/s를 유지한다. 실제로는 경사에서 느려지지만, 비교를 위해 기존과 같게 둔다.

## 8. 결정 (2026-11-09)
1. **중심 근거:** IST-1·IST-2 0.32 g. 확정.
2. **높은 B의 이름을 "121 kg 우주복 시나리오"로 바꾸고 포함한다.** 배수(EWT 3/8 g ÷ IST-1 0.32 g, 약 1.25 m/s)는 화소 판독으로 다시 구한다. 육안 판독으로는 약 1.15이고, 대부분 총 무게 차이(745 N vs 633 N)로 설명된다. [추론]
   - (다) 무게-대사량 기울기 방식은 **보류**. 사용자 지침을 기다린다.
3. **경사 속도:** 하나를 주 결과로 정하지 않고 세 방식을 모두 계산해 나란히 비교한다.
   - ㄱ. 모두 0.92 m/s. 오르막 증가분 × 속도비 1.19
   - ㄴ. 모두 0.77 m/s. 평지(IST-1 0.32 g, 0.77 m/s)와 오르막(IST-2) 실측값을 보정 없이 사용
   - ㄷ. 경사별 속도. 평지 0.92 m/s, 10% 이상 0.77 m/s, 0~10%는 속도와 대사량 모두 직선 보간, 내리막 0.92 m/s
   - 세 방식 모두 칸 이동 시간이 속도를 따르게 해서 누설과 예비분에 반영한다. 선량은 SPE off라 안 B에서는 계산하지 않는다.
   - 주의: 0.77 m/s는 시험 규칙 속도(PTS − 0.7)이고, 사람이 스스로 고른 오르막 속도가 아니다.
