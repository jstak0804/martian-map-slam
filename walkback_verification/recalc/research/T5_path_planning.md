# T5. 경로 탐색 알고리즘 선택 근거와 대안

2026-11-12 · 사용자 질문 "A*가 다익스트라보다 낫지 않나"에 대한 분석

## 현재 사용 [확인: 코드]
| 쓰는 곳 | 알고리즘 |
|---|---|
| 귀환 지도·면적 (`mars_walkback`, `spe_walkback`, `build_demo_data`) | scipy 다익스트라, 거점에서 역방향 그래프 1회 |
| 데모 모든 모드 (`demo_template.html` `dijkstra`) | 다익스트라 (이진 힙) |
| 한 점 → 한 점 경로 비교 (`metabolic_navigation.astar_o2`) | A* (휴리스틱 = 직선거리 × 모든 경사 중 1 m당 최소 산소) |

## 다익스트라를 쓰는 이유
- A*는 목표가 하나일 때 휴리스틱으로 탐색 범위를 줄인다. 휴리스틱이 허용적이면 최소 비용은 다익스트라와 같다. 더 좋은 경로를 찾는 것이 아니라 같은 경로를 더 빨리 찾는다.
- 귀환 지도는 "모든 칸 → 거점" 비용이 필요하다(일대다). 역방향 다익스트라 1회가 답을 모두 준다. 목표가 없으면 A*는 다익스트라와 같고, 칸마다 A*를 돌리면 약 53만 번의 탐색이 된다.
- 현재 위치·구조·거점 옮기기 모드도 모두 일대다다.
- 계획 E 5번: A*와 다익스트라의 비용이 같음(무작위 목표 6개, 상대 차 0) [계산]. 휴리스틱 하한은 빠른 테스트로 고정했다.

## 대안 후보
1. **자원 제약 / 다목적 탐색**(Pareto 라벨 탐색, NAMOA*, 자원 제약 최단경로)
   - 지금은 산소 최소 경로 하나에서 냉각수·선량·통신을 판정한다.
   - 다른 경로로는 모든 제약을 만족하는데도 "불가"로 판정하는 칸이 있을 수 있다 [추론].
   - 계획 J14에서 빈도를 잰다. 의미 있으면 다음 계획 후보다.
2. **임의 각도 / 연속 해법**(Theta*, Field D*, Fast Marching, 비등방이면 Ordered Upwind Method)
   - 격자 방향 편향을 줄인다. 16방향 격자는 평지에서 원 면적의 97%(CHANGELOG 13절)라, 남은 효과는 몇 % 수준이다.
   - 오르막·내리막 비대칭 비용에서는 구현이 복잡하다. 한계로 기록한다.
3. **증분 재탐색**(D* Lite, LPA*): k 변화는 모든 비용에 같은 배수라 경로가 그대로라 이점이 적다.
4. **시간 의존 탐색**: SPE 선량률의 시간 변화나 일조를 넣을 때 필요하다. 보류한다.
5. **하이브리드 A***(Kim 2025 도구): 차량 운동 제약용이라 사람 보행에는 해당하지 않는다.

## 결론
알고리즘 교체(다익스트라 → A*)는 결과를 바꾸지 않는다. 검증할 가치가 있는 것은 "산소 최소 단일 경로" 가정이 놓치는 칸의 빈도다(J14).
