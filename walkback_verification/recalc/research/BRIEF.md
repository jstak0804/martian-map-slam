# 공통 브리프: 우주복·탐사자 장착 장비로 실시간 대사량과 산소 소모를 재는 방법 조사

## 배경
화성 EVA "귀환 가능 반경" 프로젝트(walkback_verification). 남은 산소·냉각수로 거점까지 걸어 돌아올 수 있는 영역을 지형 위에 계산한다.
- 산소 소모 = 대사로 쓰는 산소 + 우주복 누설. 냉각수 소모 ≈ (대사열 + 환경 열) ÷ 증발잠열.
- 계산의 가장 큰 불확실성은 "이 사람이 지금 모델보다 몇 배 대사하는가(k)"이다. 개인차 ±15%만으로 면적이 −20 ~ +31% 변한다.
- 목표: 우주복이나 탐사자 몸에 장착되는 장비로 **실시간 대사량과 산소 소모율을 추정하고, k와 누설을 분리해 귀환 반경을 실시간으로 다시 계산하는 방법**을 찾는다.
- 이미 확인한 것: Apollo는 산소 탱크 압력, 냉각복(LCG) 열수지, 심박을 함께 써서 실시간 대사량을 추정했다(Waligora & Horrigan 1975). 짧은 구간(30분 미만)에서는 산소 압력법의 잡음이 컸다. EWT·IST 시험은 환기 유량 × 배기 CO2 농도 + 개인별 VCO2-VO2 회귀로 우주복 대사량을 쟀다. Hoffmann 2021(NTRS 20210024317)은 심박 → 대사량 회귀(R² 전체 0.40, 개인 > 0.82, 무중력 EVA 자료). ICES-2026-126(Ogilvie et al., Mars PLSS Status and Plan)에 따르면 화성 PLSS는 연속 환기 유량계, 경량 CO2 센서와 O2 농도 센서, 냉각수 주머니 연속 부피 센서를 개발 중이다. 이 문서는 이미 walkback_verification/recalc/references/ICES-2026-126_Ogilvie_MarsPLSS.txt 에 있다.

## 증거 표시 (모든 주장에 붙일 것)
- [Confirmed] 이번에 본문·초록·공식 문서·저장소를 직접 읽음. 출처 URL과 쪽/절을 함께 적는다.
- [Inference] 확인한 내용으로 추론함.
- [Unverified] 원문을 보지 못함.
- 논문 수치는 "논문이 조건 Y에서 X를 보고했다"로만 적는다. 우리 시스템의 기대 성능으로 옮기지 않는다.
- 검색 결과가 없다고 해서 문헌이 없다는 뜻은 아니다.
- 유료 벽·캡차·봇 차단은 우회하지 않는다. 막힌 원문은 목록으로 남긴다.

## 도구 요령
- NASA NTRS: `curl -s https://ntrs.nasa.gov/api/citations/<ID>` 로 메타데이터와 PDF 경로를 얻고, `https://ntrs.nasa.gov<pdf 경로>` 를 curl로 받는다.
- PDF 텍스트 추출: `walkback_verification/recalc/.venv/bin/python -I -c "import pymupdf; ..."` (PyMuPDF 설치됨).
- 받은 PDF와 추출한 텍스트는 walkback_verification/recalc/research/sources/ 에 저장한다(새 폴더, 파일명은 출처를 알 수 있게).
- 다른 파일은 수정하지 않는다.

## 출력 형식 (한국어 Markdown, 지정된 경로에 저장)
1. 요약 (5줄 이내)
2. 후보 방법 표: 방법 | 측정하는 물리량 | 필요한 센서 | 시간 분해능·지연 | 보고된 정확도(조건 포함) | 대사와 누설을 구분하는가 | 비행 실적·TRL | 근거 표시와 출처
3. 방법별 상세: 원리, 수식이나 절차(재사용 가능하면 그대로), 실패 사례·오차 원인, 우리 조건(화성, 0.38 g, 4.3 psi 순산소 우주복, 걷기 대사 300~600 W)과의 차이
4. 구현·코드·데이터: 공개 저장소가 있으면 `gh api repos/<owner>/<repo>` 로 라이선스·마지막 활동을 확인하고 Adopt / Extend / Build로 분류
5. 막힌 원문 목록, 추가 확인이 필요한 항목
6. 참고문헌 (실제로 연 것만, URL 포함)
